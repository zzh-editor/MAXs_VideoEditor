# 更新记录

## 1.0.2

- MAXs 包装先抽 3–5 帧定位福利卡硬字，再按源片实际边界盖卡并放视频标题；不复用固定坐标。
- A-Roll 推拉改为用户明确要求时才加；用户要求撤销时只移除新增推拉，保留既有 PIP 关键帧和 Studio 编辑。

## 1.0.1

- MAXs 包装新增源片 3–5 帧硬字检查；发现营销文字时完整遮罩并让遮罩跟随 A-Roll。
- MAXs 首分钟非图解段支持字幕拍点驱动的 `punch-in` / `pull-out`，并要求全程保留人脸；抠像和字幕外花字不作为默认项。

## 1.0.0

- 补上 HyperFrames talking-head 实践，以及 TikTok、Meta、YouTube 和 Bilibili 的平台/画幅安全区选项；区分官方广告模板与经验值。
- 完善随包依赖来源清单和缺失项安装流程。

## 0.9.0

- 新增依赖清单和检查/安装脚本，分发后可一次补齐视频处理、字幕、HyperFrames、图表样式和特效技能；Premiere MCP 服务仍按需连接。

## 0.8.0

- MAXs 9:16 口播图表统一使用安全框：横向 10%–88%、纵向 8%–59%；适用于 PIP+图表和纯图表。
- 将 Diagram Design、Lieflat Charts、PixelFX 纳入图表风格管线，并加入每 7 天到期时在下一次相关任务中查询上游的规则。

## 0.7.0

- 技研Labs 图解改为活动片段全画幅炭黑底，底部至少 210px 留作字幕禁入区。
- 渲染验证后新增 Premiere Pro 导入确认；用户同意后将独立图解移入工程目录、导入 `hyperframes` bin，并按字幕时间放入序列。

## 0.6.0

- 口播和直播切片默认不加品牌片头、不询问；技研课程/直播继续使用固定片头。
- 区分内容 Hook 与品牌片头；支持 Hook 源段重复、Hook 版 SRT 和主片整体后移，保留原始 SRT。
- Hook 到 A-Roll 的转场请求默认使用账号强调色 0.24 秒推擦。
- `retime.py` 支持 `hook_duplicate`，同时映射 Hook 视频段和字幕。

## 0.5.0

- 中文字幕和新增中文文案统一转为简体；优先使用 `video-transcribe` 的简体提示，若识别结果含繁体，在字幕校对阶段修正，不增加必需依赖。
- Studio 字幕默认放在独立可编辑轨道；渲染前确认是否烧录，干净导出不隐藏或改写主项目轨道。
- 每条视频在字幕定稿后都进行内容扫描；确认后的动画 b-roll 默认集成到主项目 graphics 轨道，单独项目改为用户要求时才使用。

## 0.4.0

- 概念 b-roll 新增四条硬规则：静止段落必须有微妙镜头运动；所有过渡走三次贝塞尔缓动，不用线性插值；平面图形用正交相机正视，避免方框被拉成梯形；说明文字按讲给同学听的口吻写，标题不超过 7 个字。
- 依据「TA 入门课 week10」三条切片产出三段 Three.js b-roll：立方体区间同时驱动材质与粒子、CPU 逐个算与 GPU 并行算、Mesh 表面粒子按三角形与按面积两种分布。
- 暗底版本：背景 `#161616`，强调色仍为 `#ADF911`。
- 使用 TA 入门课的立方体、CPU/GPU 和网格采样主题制作了三段图解样片，用于检验 3D 讲解动效和字幕安全区。
- 0.4.0 管线调整：b-roll 移到字幕完成之后，由技能依据字幕内容自动判定需要图解的区间并输出候选清单（字幕编号、主张、关系、预计时长），用户确认后再制作；b-roll 独立成项目，产出目录默认放在用户传入素材的同级目录（已有项目不搬家）。
- 0.3.3 新增"画面要活就动图形本身"的规则：线条画出来、槽位预亮、阵列闪现；样片里第二条开场用 CPU 槽位逐个预亮 + GPU 阵列闪一下，第三条开场用线段画出容器和两个子系统。
- 0.3.2 修订：去掉全部镜头运动，相机固定不动；新增"相邻两段内容不互相侵入"的交接规则。0.3.1 曾尝试用正交推进代替平移，实际仍会让图形在画面里缓慢位移，已撤回。
- 0.3.1 新增"多个图形用连续形状变化带动视线"的规则，粒子场改分布时用连续形变代替淡入淡出。

## 0.2.0

- 支持把字幕中的知识点做成 3D/图形化 b-roll；原文有比喻时沿用并映射回实际概念，无例子且用户未指定时先询问。
- 概念 b-roll 默认控制在 15–30 秒，写清分镜与字幕来源；已有正确 SRT 时直接使用，不重复转写或擅自读取其他音频。
- 使用 Three.js 时从 HyperFrames 时间确定性地重建每帧，优先把解释做成可独立插入、保留原课音轨的无声视觉段。
- 本版本样片依据 `切片_Enhancer.srt` 第 11–47 条，未使用原 M4A。
- 分镜/样式采用 Lieflat Charts 的 Mono 编辑语法；Three.js 参数与文字层可在 Studio 中调整。
