# 品牌与片头

## 固定素材

技能自带用户素材副本，创建项目时复制到项目 `assets/`，使用项目相对路径；不要让成片依赖 Downloads 目录继续存在。

| 用途 | 技能内路径 | 来源 |
| --- | --- | --- |
| 所有新增文字 | `assets/fonts/MiSansVF.ttf` | 用户提供，已随技能打包 |
| 技研课程/直播片头音效 | `assets/audio/Swoosh_01.wav` | 用户提供，已随技能打包 |

两份资产来自用户，使用原文件的本地副本。文件指纹在 `assets/provenance.json`。

字体内部 family 为 `MiSans VF`，`wght` 轴实测为 150–700。标题、正文、字幕、tips、代码文字和数字均用这一字体；层级只通过字号、字重、间距和颜色建立。源视频已有文字是素材像素，不替换。不要下载第二种字体、选择字体配对或静默回退。

```css
@font-face {
  font-family: "MiSans VF";
  src: url("./assets/fonts/MiSansVF.ttf") format("truetype");
  font-weight: 150 700;
  font-style: normal;
  font-display: block;
}
body { font-family: "MiSans VF"; font-synthesis: none; }
```

渲染前确认字体加载成功，再测量文字和建立时间线；失败时修复本地路径。检查所有新增文本的字体和字形覆盖，包括公式需要的符号；缺字时询问表达方式，不能悄悄替换字体。

## Hook 与品牌片头

品牌片头是额外设计的账号包装；Hook 是从原片挑出的一段内容放到视频开头。不要把两者混为一谈，也不要因为用户要求 Hook 再询问品牌片头。

用户要求把源片片段做成 Hook 时：

1. 用字幕和原声找完整语句的源入点、出点。默认复制到 0 秒，原片段仍留在原位置，除非用户要求替换或删除。
2. Hook 视频保留原声；如果同一段也保留在主片，说明原声会在片头和原位置各出现一次。
3. `edit-plan.json` 写 `hook_duplicate`，`intro_ms` 等于 Hook 时长；主片的图表、PIP、tips、字幕、落版和其他轨道一并后移，`data-media-start` 仍指向原片时间。
4. 新建 Hook 版 SRT，不覆盖基线 SRT；Hook 字幕从源片 cue 复制，主片字幕按同一时间映射后移。字幕跨剪切点时先按实际词级语音拆分，不按字符比例猜时间。
5. 用户要求 Hook 与 A-Roll 之间转场时，默认用账号强调色做 0.24 秒全屏推擦。确认转场层盖住字幕，转场后首句仍能读到。

口播和直播切片若未要求 Hook，直接从源视频开头播放；不主动提议或询问是否加品牌片头。

## 技研片头的已知视觉

参考图用于文字排版：上行短标题放在实心绿色矩形中，下行白色说明更宽，两行作为整体居中。用户已明确标题覆盖在视频开头，参考图里的黑色不能实现为片头背景。矩形用直角，没有渐变和发光。示例文字“如何用半隐式欧拉法 / 去计算并实现刚体/弹簧的力量回弹衰减”仅为用户参考图，不能套到题材不同的视频。

用户所称 zoom in 的实际视觉方向为**从超大缩小至中央**。保持同一标题组连续缩放，初始边界超过画面，快速缩入后减速，以一次小幅回弹稳定到 `scale: 1`。不要反做成小字放大，也不要替换成飞入、猛烈抖动或持续呼吸。

参考实现沿用 registry 的 `headline-slam` 缩入结构，按需求移除其抖动、漂移和上甩退出，改为有界回弹。它的原生效果不等于已确认的品牌动效。

标题层入场比视频首帧晚 5 个输出帧，即 `data-start = 5 / data-fps`（30 fps 项目为 `0.166667s`）。视频与原声从 0 开始，Swoosh 也从 0 开始。保持用户指定的五帧关系，不因素材帧率或峰值探测自动挪动。入场约 0.72 秒，`scale: 4 -> 1`，`back.out(0.52)`，短透明度显现；实际回弹约为最终尺寸的 2.7%。需随文字宽度检查初始边界确实超出画面。标题稳定后保持可读，再撤去叠加层，底下的视频持续播放。示例标题层显示 2.8 秒；时长、字号和两行间距是试片参数，用户看过后才能当作定稿。

可复用的起始子组合在 `assets/jiyan-opener.html`。复制到项目 `compositions/` 后，修改两行文字；项目根页面加载本地 GSAP。字体路径相对项目 `compositions/` 指向 `../assets/fonts/MiSansVF.ttf`。音效放在父时间线，避免子组合重复带声。复制样式后检查文字宽度，不能把参考图文字当作本次课程内容。

技研课程/直播片头固定为透明叠加层，在精剪后首帧的第 5 个输出帧开始入场；底下的视频、原声和 Swoosh 从 0 连续播放。2.8 秒表示标题层的显示时长，不是插入时长，`edit-plan.json` 的 `intro_ms` 必须为 0。标题消失后继续同一视频，不增加片长，不移动字幕，不暂停或遮黑素材。首段有字幕时保留底部字幕带，与中央标题避让。白色说明文字可使用克制的黑色描边或阴影提升复杂背景上的可读性。

## 固定音效

播放 `Swoosh_01.wav` 一次，不循环，不额外生成音效。固定音量为素材原始电平的 66%，HyperFrames `data-volume="0.66"`；不要把百分数换算为 −8 dB，也不要预先衰减音源。视频与 Swoosh 的开始时间为 0，标题层在 5 帧后入场。文件实测 1.5 秒、44.1 kHz、双声道。

音量为线性百分比，不是 dB：直接设置 `data-volume="0.66"`。不得改回旧值 `0.3981071705534972`，也不要预先衰减文件后再重复加轨道增益。

原声默认保持原有增益；需要调整时单独说明。Swoosh 不是 BGM，不对它执行音乐生成或背景配乐 duck/carve。

## MAXs 口播 / 直播竖屏包装

- 开始包装前从源片均匀抽 3–5 帧，定位烧录在画面里的福利卡文字区域；不同视频按实际文字边界重新定框，不能沿用固定坐标。标题板完整盖住福利卡及其底栏，视频标题放在标题板上，并让二者随 A-Roll 变换进入 PIP。其他画面文字不自动遮，除非用户指定；不靠裁切画面避字或躲脸。
- MAXs 默认保留原 A-Roll 画幅；不为增加节奏自动加 `punch-in` / `pull-out`。用户明确要求后，才按字幕拍点添加少量重构图，并抽查最大缩放帧，确认整张脸和头顶留在画内；用户认为推拉不好时，只撤销新增的 A-Roll 推拉，保留原有图解 PIP 关键帧和用户编辑。
- 全屏 A-Roll 字幕跟随首条审核字幕的位置；上方图表 + 底部 PIP 用独立 chart-PIP 位置，按 `subtitle-handoff.md` 的参考 cue 放置。
- MAXs 9:16 口播/直播图表，无论是 PIP+图表还是纯图表，图表主体统一限制在安全框 `x=10%–88%`、`y=8%–59%`；2160×3840 下约为 `x=216–1901px`、`y=307–2266px`。节点、内部标签、图例、连线、标注及动效的完整行程都算图表元素，必须始终留在框内。独立段落标题可用标题位；不把它当作图表主体。其他竖屏尺寸按比例换算。
- 取消独立漂浮花字；仅在全屏 A-Roll 的原字幕中用 MAXs 蓝 `#134FFF` 高亮具体关键词，字白色。只包住关键词，不改变整行底色、不添加概括词；字幕没有合适关键词或画面有图表时就不高亮。
- 图表不加“蓝色表示当前重点”等说明品牌色的小字。只有颜色/线型编码真实类别且不解释会难以读懂时，才写语义图例。

## 图表视觉基线

- 参考 [Diagram Design](https://github.com/cathrynlavery/diagram-design) 的 45 种图解分类与编辑原则，按信息关系选形式；不复制其默认橙色、字体或 HTML 模板。HyperFrames 项目沿用 MiSans VF 和时间线契约。
- MAXs 图解以白/浅灰底、黑灰文字和 `#134FFF` 为主；蓝色只落在 1–2 个视觉焦点。技研Labs 使用 `#ADF911`，强调色底配黑字；不沿用 MAXs 蓝，也不套 Diagram Design 的橙色。
- 技研Labs 活动图解全画幅铺 `#161616`，不留白边或透明外框；透明 WebM 只在图解片段以外的时间保留透明。底部 19% 留作字幕禁入区；1920×1080 画面至少空出 210px，其他画幅按高度等比例计算。文字、图形、连线和装饰都不得进入这一区域。
- 优先删掉重复节点、装饰线和无意义图例。连线要说明方向或关系；阴影不用，边线细，圆角克制，不做一排同款卡片。
- 图例只有在颜色、形状或线型承载真实数据类别且读者无法自行辨认时才加，放到图表边缘或底部，不浮在关系节点之间。

## MAXs / 技研Labs 共用落版

- MAXs 中文竖版落版也可作为技研Labs 的共同片尾；用户要求两账号统一时使用同一素材，不另做一张技研Labs 版本。落版不是技能内置资产，只有用户提供或当前剪辑环境能定位到获准使用的品牌素材时才添加；不能依赖某台机器上的固定绝对路径。
- 文件名中的 `Black` / `White` 指文字颜色，不表示背景颜色。选择前抽帧检查实际底色，再按 A-Roll 最后一帧整体亮度选对比清楚的版本。当前明亮场景示例使用 `4K/CHN_Version/MAXs Slogan Logo_Black_ Vertical.mp4`，黑字白底。
- 按画幅和语言选择匹配版本；将落版复制到项目 `assets/` 并接在 A-Roll 后。核对媒体自身的尺寸、时长和音轨，不以文件夹名称代替媒体信息；保留素材自带音轨，静音前先问用户。
