# 精简 cue map

适用于需要按字幕排图解、卡片、PIP、音效或视觉检查点的项目。字幕定稿后从最终 SRT 生成一次，供后续阶段复用；纯字幕任务或没有 cue 定时视觉时跳过。

把表达同一关系的相邻 cues 合并成一行，不复制完整字幕。保留这些列：

| 列 | 内容 |
| --- | --- |
| Cue | 编号或相邻编号范围 |
| 成片时间 | 组内起止时间，取自最终 SRT |
| 关系 | 一句短摘要，如“候选池不同”或“本科从入学开始准备” |
| 画面 | `full-frame A-roll`、`chart-PIP`、图解阶段或转场音效锚点 |
| 组合 | 对应 composition ID 和成片起止时间；尚未制作时留空 |

字幕原文仍以最终 SRT 为准；cue map 不替代字幕文件，也不补充字幕未支持的事实。内容扫描、图表和 PIP 排期、字幕位置、音效锚点及预渲染抽帧都复用这张表。剪辑或字幕时间改变时只更新受影响的行，不重建整张表。
