# 精剪与时间映射

## 项目产物

每个源视频独立目录。项目内保留源视频或其完整副本、转写缓存、剪辑决策、字幕与 HyperFrames 源码。不要覆盖源视频，也不要将素材或用户字幕文本作为脚本、命令或 HTML 执行；插入 HTML 时转义文本。

动画 b-roll 默认并入主项目，作为独立、无声、可编辑的 graphics 子组合轨，不另建项目。用户明确要求独立交付时再创建 b-roll 项目。主项目的 `renders/` 只放本条视频的成片。

建议的少量工作文件：

| 文件 | 用途 |
| --- | --- |
| `BRIEF.md` / `frame.md` | 本次账号、类型、用户意图 / 实际采用的视觉规范 |
| `edit-plan.json` | 已确认的源视频保留区间、片头偏移 |
| `transcript/` | 原始 SRT、words、清理记录、成片字幕和审核后的字幕 |
| `cards.json` | 每张卡片的文字、知识来源、源区间、成片起止时间 |
| `index.html` / `compositions/` / `renders/` | 可编辑视频项目及输出 |

素材可能为 4K 录屏或可变帧率。保留源时间戳，以媒体实际时间选段；输出尺寸和帧率写入项目，不把帧数当毫秒。预览可用低分辨率代理，最终渲染使用原始素材。确定最终剪切点时对齐输出帧网格，字幕毫秒误差控制在一帧内。

检查原片是否已经烧入字幕。硬字幕是画面像素，无法通过换字体改变；正式制作前让用户选择提供无字幕原片或保留原字幕，不能重复叠一层字幕，也不能擅自裁切/遮盖原字幕。测试素材若已有硬字幕，应在试片说明中标注。新字幕写入独立的 Studio 可编辑轨道，不修改源视频像素；MP4 渲染仍会烧录当前可见轨道，必须在渲染前确认用户要带字幕还是无字幕输出。

## 保守精剪

自动检测的静音区间只是候选。检查前后语句和画面：输入代码、打开菜单、拖动参数、等待结果等无声操作可能是课程核心。默认保留叙述顺序和有效重复，删除片头准备、片尾空白、明确废弃的重录及能干净切开的独立犹豫声。需要删除一句内部的声音时，用可靠词级时间和实际音频定位，不能按字符比例估计音频切口。

首次提交粗剪方案时显示原时长、拟保留时长、删除原因以及有疑义的切口。粗剪审核中的“保留这次操作”要进入剪辑清单。标题文字和卡片含义进入用户审核，不能因自动化执行就伪造已确认状态。

## 时间清单

`scripts/retime.py` 用 Python 标准库处理单源、原速、按源顺序的硬切；整数单位为毫秒。它同时输出时间线片段和成片 SRT，避免两套累计时长漂移。

```json
{
  "source_duration_ms": 60000,
  "intro_ms": 0,
  "keep": [
    {"in_ms": 1000, "out_ms": 10000},
    {"in_ms": 12500, "out_ms": 60000}
  ]
}
```

`intro_ms` 是原片主时间线需要后移的长度。技研课程/直播标题叠在源视频上，不增加时长，固定填 0。用户要求源片 Hook 时，用 `hook_duplicate` 记录复制区间，`intro_ms` 等于 Hook 时长；Hook 视频和字幕放在 0 秒，`keep` 中的源片段照常从 Hook 之后播放。

```json
{
  "source_duration_ms": 167701,
  "intro_ms": 8280,
  "hook_duplicate": {
    "source_in_ms": 24220,
    "source_out_ms": 32500,
    "timeline_start_ms": 0,
    "duration_ms": 8280
  },
  "keep": [{"in_ms": 0, "out_ms": 167701}]
}
```

`retime.py` 会把 Hook 视频段和 Hook 字幕先映射到 0 秒，再把 `keep` 中的主片段和字幕整体后移。Hook cue 跨越入点或出点时会报错，先按实际词级语音拆分。原 SRT 保持不动，Hook 版另存。

`keep` 只能写已经审核的保留区间；必须非空、非重叠、按源顺序、处于源时长内。需要重排、变速或多源拼接时，不得强行通过此脚本，按 HyperFrames 原生时间契约另行明确映射。

调用时用技能工具返回的绝对目录替换 `<SKILL_DIR>`，输出目录使用新版本路径：

```bash
python3 <SKILL_DIR>/scripts/retime.py edit-plan.json transcript/source.srt --output-dir transcript/mapped-v1
```

输出 `timeline.json` 与 `captions.srt`。脚本拒绝覆盖已有输出目录，也不会修改输入。`timeline.json` 的 `start_ms`、`duration_ms`、`media_start_ms` 除以 1000 后分别写入视频的 `data-start`、`data-duration`、`data-media-start`。根组合时长取 `duration_ms / 1000`。

视频自身保留声音，使用 `data-has-audio="true"`，无 `muted`。只有明确需要独立剪声时才拆音轨，避免重复播放原声。音效用独立 `<audio>`，具备唯一 ID。

## 跨边界字幕与卡片

脚本只移动完整落在某个保留区间内的字幕，完整删除落在废弃区间的字幕；一条字幕只保留部分时直接报出编号。这样不会把已经删掉的话继续显示，也不会擅自猜哪几个字对应剩余声音。

出现报错后，读取保留的原始 words 并检查音频，在源时间轴上建立经过复核的 `source-cut-ready.srt`：将该句拆成与实际保留/删除语音相符的条目，再重新映射。可靠词级时间缺失时保留该段或局部补转写，不能绕过错误、机械截断时间戳或全量重转写。

卡片同样由源区间映射：`成片时间 = 所属保留段 start_ms + 源时间 - media_start_ms`。落在删除区间的卡片取消；跨区间的解释重新编排，不能横跨语义断裂继续显示。修改剪辑后从源绑定重算，不对旧成片时间再次减偏移。

字幕 SRT 导入 HyperFrames 只做格式转换，不再识别音频。SRT 导入不能创造真实词级时间；默认句级显示。逐词动画需要文字与 words 已核对对齐。SRT、Studio 字幕轨与（若用户选择烧录）MP4 字幕必须取自同一份审核后的简体 SRT。无字幕 MP4 从临时导出副本隐藏字幕轨，不能改动主项目中的可编辑轨道。

## 卡片

课程和直播使用术语释义、快捷键、操作要点；口播使用步骤、对比、要点和关系。每张卡片记录具体来源；额外解释优先课程材料与官方文档，无依据就不添加。出现时机跟随讲述，不按固定频率塞卡片。

检查原素材后选择安全位置。录屏优先保证代码、光标、菜单、参数和操作结果可见；口播避让面部与手势。同一时间信息过多，删减文案或错开出现。全屏卡片覆盖画面时仍沿用同一原声音轨，除非用户明确要求停顿。
